# Seoul Bike Digital Twin – Desktop Application Proposal

**Application name:** Seoul Bike Digital Twin

### Main Purpose

The main purpose of our desktop application is to predict hourly bicycle rental demand in Seoul using historical rental data, weather information, calibrated models and machine learning.

The application will provide an interactive interface for demand forecasting, model comparison and decision support.

### Main Users

Our primary user is a **Bike Sharing Operations Manager**, who needs to understand expected demand.

### Objectives

- Forecast hourly bicycle rental demand using our existing calibrated and AI-enhanced models.
- Integrate forecast weather information through the Open-Meteo API.
- Compare the performance of different forecasting models on historical test data.
- Support operational planning through data-driven forecasts and simulations.

### Main Use Cases

**UC1 – Future Demand Forecasting:** The user selects a timeline, and the application estimates hourly bicycle demand.

**UC2 – Model Comparison:** The user compares predictions from the calibrated Week 5 model, Direct AI, Forecast AI and Hybrid AI models.

**UC3 – What-if Simulation:** The user changes weather conditions to explore possible demand scenarios.

**UC4 – Export Results:** The user exports forecasts, evaluation tables and charts.
